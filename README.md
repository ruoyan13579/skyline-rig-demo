# 城墙区 · 立体机动训练

用虚幻引擎 5.6.1 制作的 Windows 单人第三人称飞行 Demo。左右双钩分别连接建筑，收索起飞、单钩绕楼、松手借惯性穿过街口，再用喷气调整方向和速度。

[下载 Windows 试玩版](https://github.com/ruoyan13579/skyline-rig-demo/releases/latest/download/SkylineRig-Demo-Win64.zip)

## 开始试玩

1. 下载 `SkylineRig-Demo-Win64.zip`，约 264 MB。
2. 完整解压压缩包。
3. 打开解压出的 `SkylineRig-Demo-Win64` 文件夹，双击 `SkylineRig.exe`。

适用于配有键盘、鼠标和 DirectX 11 显卡的 64 位 Windows 电脑。运行库和中文操作说明已放进包内。首次启动如提示缺少 Microsoft Visual C++ 运行库，可运行包内的 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`，安装后再次打开游戏。

## 第一趟飞行

从石台望向街道，抬高视线寻找楼檐上的橙色和蓝色菱形。按住鼠标左键或右键收索起飞，朝绿环松钩，轻按左 Shift 补速。顺序穿过六道环可以完成计时，也可以自由探索屋顶。

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 观察、瞄准并调整喷气方向 |
| 鼠标左键 / 右键 | 按住控制对应钩索，松开保留速度 |
| W A S D | 地面移动、空中微调 |
| 空格 | 跳跃 |
| 左 Shift | 沿视线喷气，停喷后逐渐回气 |
| H | 展开或收起操作提示 |
| R | 返回起点、补满气体并重新计时 |
| Alt + F4 | 退出游戏 |
